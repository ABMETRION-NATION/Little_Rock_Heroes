# Little Rock Heroes

Family-based action adventure game built around character switching, unique abilities, and multi-style gameplay.

## Core Idea
A family of rock-like characters travels across dangerous worlds to rescue their missing sister.

## Pillars
- Family-first gameplay (switching matters)
- Multiple playstyles (optional, not forced)
- Rock-themed worlds and enemies
- Scalable system for multiplayer + expansion
