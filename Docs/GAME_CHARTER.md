# GAME CHARTER

## Core Law
FUN > FEATURES

## System Order
CORE → CONTENT → MULTIPLAYER → EXPANSION

## Identity Rule
The game MUST include:
- Family system
- Character switching
- Story (missing sister)

## No Default State
- No placeholder art
- No generic mechanics
- No unused systems

## Build Rule
Do NOT overload Version 1 with systems.
Add depth through content, not complexity.
